# BSD Command Centre

Priorities and client portfolio in one place, for Blue Sense Digital.

- Static site (plain HTML, CSS and JS), hosted on GitHub Pages.
- Sign-in, data and live updates come from Supabase. Row-level security only returns data to approved accounts, so the repo holds no task or client data.
- Views: `#/priorities` (home), `#/clients`, `#/clients/<key>`.
